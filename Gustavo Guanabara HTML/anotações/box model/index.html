Estudando tipos de box model:



Tipos:


1. box-level:
O box-level ocupa uma linha inteira. Traduzindo o nome, fica: Level da caixa. os tipos dele são:

<h1> até o <h6>

<p>

e mais alguns (principalmente parágrafos)


2. inline-level:
o inline-level continua da mesma linha. Traduzindo o nome, fica: Level na linha. os tipos dele são:

<a>

<form>

<button>

e mais alguns (principalmente interação )
